# pc12-135录入：任务书 / 飞行报告 → 云执照录入 Excel 转换规则

用户会发来**飞行任务书**（正面：机型、机号、日期、航班号、航段）和**飞行报告**（各段时刻、时长、备注里的进近方式）的照片。
识别后按下面规则生成 Excel，交给 `filler.py` 自动录入云执照。

## 输出格式（固定，不要增减）

- 只有一个工作表「飞行记录」，第一行表头，每个航段一行。
- **只有这 16 列，顺序固定**，不要加任何其他列或工作表（任务书里的重量、航路、人员、油量、POB 等都不要放）：

  `日期 | 航班号 | 航空器型号 | 航空器登记号 | 起飞站 | 降落站 | 出发时刻 | 到达时刻 | 职位 | 进近方式 | 夜间飞行经历时间 | 真实仪表时间 | 转场时间 | 昼间着陆次数 | 夜间着陆次数 | 备注`
- 日期格式 `yyyy-mm-dd`，时刻 `hh:mm`，时长 `[h]:mm`；用 `report_to_excel.py` 生成即可保证格式一致。

## 每列取值

| 列 | 来源 / 计算 |
| --- | --- |
| 日期 | 任务书「年/月/日」（与飞行报告日期不一致时以任务书为准，并告知用户） |
| 航班号 | 任务书「航班号」（如 WUA2760） |
| 航空器型号 | 任务书「机型」（如 PC-12） |
| 航空器登记号 | 任务书「机号」（如 B-12R6） |
| 起飞站 / 降落站 | 任务书「航段」，与飞行报告核对（四字码，如 ZBAL / ZBEN / ZBAR） |
| **出发时刻** | 飞行报告「**滑出时刻**」 |
| **到达时刻** | 飞行报告「**滑行终止时刻**」（云执照据此自动算飞行经历时间，不用填经历时间） |
| 职位 | 默认「机长」；不确定时问用户 |
| 进近方式 | 飞行报告备注（如「WUA2760 VOR」「WUA2761 目视」） |
| 夜间飞行经历时间 | 飞行报告「夜航时间」，没有就留空 |
| **真实仪表时间** | **空中时间 = 起飞时刻 → 降落时刻**（计算得出） |
| 转场时间 | 起飞站 ≠ 降落站时 = 滑出 → 滑行终止；起降同一机场留空 |
| 昼间着陆次数 | 每段 1（任务书飞行条件为昼间时） |
| 夜间着陆次数 | 夜间着陆时填，否则留空 |
| 备注 | 留空 |

## 核对（在对话里告诉用户，不写进 Excel）

按报告注释的定义用时刻计算，与手写值逐段比对：
- 空中时间 = 起飞 → 降落
- 经历时间 = 滑出 → 滑行终止
- 合计时间 = 开车 → 关车
- 地面时间 = 合计 − 空中
- 各段合计时间之和、着陆次数与报告「总计」比对

不一致、字迹不清、任务书与报告矛盾的地方，在回复里列出来让用户确认。

## 生成步骤

1. 识别照片，把数据写成 JSON（字段见 `report_to_excel.py` 开头的示例）。
2. 运行 `python report_to_excel.py legs.json -o flights_<日期>.xlsx`，会顺带打印与手写值不一致的地方。
3. 用 `filler.py` 的 `load_rows` 读一遍确认，然后把文件发给用户。
4. **生成的 Excel 和 JSON 含人名、机号等信息，不要提交到 Git 仓库**（仓库可能是公开的），只通过对话发给用户。
