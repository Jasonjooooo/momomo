v2.26.0 新增：热点雷达（见「三½、热点雷达」）。

v2.25.0 新增：取关池（见「七、清理未回关」）。

一个插件，两个用途：
  A. 清理没回关你的人（v1 的功能）
  B. 在 #蓝V互关 帖子里，找出你还没关注的人

所有关注、取关都要你自己点，插件不会自动批量操作。

v2.1 新增：
  - 定时提醒：默认每 15 分钟弹一次提醒，点提醒直接打开最新的互关帖
  - 只看回复多的帖子：默认只标出回复数 ≥ 150 的互关帖
  - 一键关注：帖子里的人旁边有蓝色「关注」按钮，不用打开主页就能关注

面板太长时：首页/搜索页面板只留常用按钮，关键词、回复数、每轮人数、提醒间隔、回复目标收在「设置」里，
热度、淡化、试提醒收在「显示与提醒」里，点一下展开，再点收起，下次打开会记住。面板超出屏幕时可以在面板里上下滚动。

一、安装 / 升级
━━━━━━━━━━━━━━━━━━━━━━━━
已经装过旧版：
  1. 把这次的文件，覆盖到原来那个「回关助手」文件夹里（文件夹位置别变）。
  2. 打开 chrome://extensions，在「回关助手」卡片上点刷新按钮（圆形箭头）。
  3. 把已经打开的 X 页面刷新一下。
  这样升级，之前的「保留」名单和取关记录都还在。

第一次装：
  1. 解压，把「回关助手」文件夹放在一个不会误删的位置。
  2. Chrome 地址栏输入 chrome://extensions 回车，打开右上角「开发者模式」。
  3. 点「加载已解压的扩展程序」，选中「回关助手」文件夹。

需要 Chrome 111 或更新的版本。

二、找互关：#蓝V互关
━━━━━━━━━━━━━━━━━━━━━━━━
最快的用法（每条帖子十几秒）：
  1. 15 分钟提醒弹出来，点它，会直接打开下一条回复够多、还没处理的互关帖。
     （或者在首页/搜索页面板点「打开下一条没处理的互关帖 →」）
  2. 在帖子页点「下滑到最后一条」，等它滑到底。
  3. 连按 F 键：每按一下，关注名单里下一个绿色「容易回关」的人。两次之间至少隔 3 秒。
     名单里绿色的人自动排在最前面。没有绿色的了，面板会告诉你。
  4. 点「下一条互关帖 →」，自动回到搜索页、打开下一条。
  每一次关注都是你自己按的，插件不会自己关注任何人。

1. 打开 X 首页或搜索页，右下角面板点「搜索最新的 #蓝V互关（回复 ≥ 150）」。
   搜出来的是按时间排序、回复数至少 150 的最新互关帖。
   每条帖子右上角（Grok 图标左边）会有几个小标签，浮在帖子上，不占地方：
   - 蓝色「互关 312」：互关帖，312 条回复，帖子左边也有蓝线。旁边「打开」点了在新标签页打开。
   - 灰色「互关 45<150」：带关键词，但回复不到你设的数。
   最右边的彩色标签是「每小时浏览量」，比如「1.2万/时」，颜色表示热度：
     灰 = 每小时不到 500    黄 = 500–1999    橙 = 2000–9999    红 = 1 万以上
   红色的是正在爆的帖子。数字是浏览总数 ÷ 发布时间算出来的平均值。
   帖子没显示浏览量的（有些帖子不显示），就不出标签。
   右上角还可能出现：
   - 紫色闪动的「抢」：发出来不到 1 小时、每小时浏览 2000 以上、回复还不到 30 条。现在回复最容易排在前面，拿到最多曝光。
   - 绿色「已回」：你回复过这条，不用再点进去。
   - 灰色「已处理」：这条互关帖你已经处理完了，整条帖子变灰，不用再点进去。
   首页、搜索页、个人主页（你自己的和别人的，包括「回复」「媒体」等分页）上的所有帖子都会显示这个标签。
   看自己帖子的热度：点左边「个人资料」就行。不想要的话，面板里点「所有帖子都显示热度」关掉。
   - 关键词可以在面板里改，多个用逗号隔开，比如：蓝V互关,互关,有关必回
   - 「回复数至少」可以改成别的数字，填 0 就不按回复数筛。
2. 点「打开帖子」，在新标签页里打开。
3. 在帖子页，面板点「下滑到最后一条」。它会慢慢往下滑，遇到「显示更多回复」会自动点开，到底自动停。
4. 面板里列出你还没关注的人。回复旁边也有红色「未关注」标记。
   - 「未关注」：插件从 X 页面数据里确认了你没关注他
   - 「可能未关注」：这个人的关注状态没读到，打开主页时自己看一眼
   每个人旁边还会显示账号质量，比如「3000粉/2900关 · 容易回关」：
   - 绿色「容易回关」：他关注的人和粉丝差不多多，多半会回关你。优先关注这种。
   - 橙色「大号难回」：粉丝上万、几乎不关注别人，很少回关。
   - 橙色「回关率低」：关注的人比粉丝少很多，回关的可能小。
   读不到数据的人不显示，不代表质量差。
5. 点蓝色「关注」，直接关注，不用打开他的主页。关注成功后，这个人会从名单里划掉。
   - 每点一次只关注一个人，两次之间至少隔 3 秒。每天关注多少个不设上限。
   - 想先看看这个人是谁，点「主页」，在新标签页里看完再手动关注，插件一样会记下来。
   - 直接关注失败时，插件会自动帮你打开他的主页，你在那里手动点「关注」。
   - X 提示「关注太多」时，面板会变黄，今天就停下。
6. 处理完一条互关帖：
   - 自动：点过「下滑到最后一条」，再把名单里的人都关注完，插件会自动标记这条「已处理」。
   - 手动：随时点面板里的「这条处理完了」。再点一次可以取消。
   标记后，在首页、搜索页刷到这条，会变灰、标着「已处理」，不再算进「互关帖」数量。记录保留两周。
7. 「只看蓝V」默认开着，非蓝V的回复者不会列出来。想全部列出就点一下关掉。

不需要先把你关注的八千多人滑一遍：插件直接读帖子里每个人的关注状态。

屏蔽词（X 自带的「静音字词」对中文常常不管用，用这个）：
  - 首页或搜索页面板 →「设置」→「屏蔽词」，多个用逗号隔开，比如：约炮,裸聊,代开发票。
  - 首页、搜索页、帖子页、个人主页里，帖子文字、引用的帖子、发帖人名字里带这些词的，折叠成一行
    「已隐藏一条帖子（含屏蔽词「约炮」）」，点「显示」可以展开看，再点「收起」。
  - 你点开的那条帖子本身不折叠（下面的回复照样折叠）。不分大小写，中间夹空格也能认出来（「约 炮」也算）。
  - 热点雷达也不收、不统计带屏蔽词的帖子。
  - 这只是在你的浏览器里藏起来，X 不知道，也不会影响推荐。想让 X 少推这类，在帖子右上角「…」点「不感兴趣」。

待关注池（跨帖子攒人，回到首页一口气关）：
  - 你打开过的互关帖里，标着绿色「容易回关」、你还没关注、以前也没取关过的人，会自动放进池子。
    大号难回、回关率低的不会进。开着「只看蓝V」时，只收蓝V。
  - 面板右上角「池子 N」就是现在池子里有多少人，在首页、搜索页、帖子页都能点开。
  - 池子里关注的人和粉丝最接近的排在最前面（最可能回关）。点「关注」，或者按 F 关注下一个，一次一个、两次之间至少 3 秒。
  - 关注了的人自动出池；不想关的点「×」移出；超过 7 天没关的自动清掉；最多存 500 人。
  - 从池子里关注的人，同样算进「这一轮已关注 n / 15」。点「← 返回」回到原来的面板。

三、待回复评论
━━━━━━━━━━━━━━━━━━━━━━━━
打开方式：首页或搜索页面板里点「待回复评论 N ↗」（N 是还没回的条数）；或者右键点浏览器右上角回关助手图标 →「待回复评论」。

1. 点「抓取最新评论」：插件会打开你的个人主页，找出你最近两天的主帖（转帖不算；最多 50 条），
   只打开「有新评论」的帖子，把下面别人的评论收进来，收完自动关掉那个页面、回到这里。
   打开帖子后会一直往下翻，遇到「显示更多回复」会自动点开（X 常把新评论、小号评论折叠起来）。
   X 打开帖子时评论要晚几秒才出来，插件会等评论加载出来再读；读到的比回复数少，会回到顶上再读一遍。
   扫过的帖子会做标记（记下当时的回复数）：下次回复数没涨就跳过；没人回复的也不打开。
   上次一条评论都没读到的，下次一定重新打开。
   所以第一次会慢一点，之后一般只打开几条。你在这里发出的回复也会记上，不会因为它多打开一次。
2. 只收你还没回的：一条评论下面紧跟着就是你的回复，或者插件记得你回过，就算回过了，不收。
   这是按页面样子判断的，偶尔会判断错：漏掉的点「撤销」放回来，回过的点「已回复 ✓」。
3. 每条评论下面有回复框，写好点「回复」（或按 ⌘/Ctrl + 回车）就发出去：
   插件会打开 X 的「回复这条」页面（内容已填好）、替你点发送、发完关掉，屏幕会闪一下。
   发成功后这条自动划掉，「已处理」里能看到你回复了什么。
   没发出去时，那个 X 页面会留着，你可以在那里看看提示、自己点「回复」。
4. 其他按钮：「已回复 ✓」手动标掉；「忽略」不用回的；「在 X 打开」看上下文或者用 AI 回复助手。
5. 「已处理」里点「撤销」可以放回「待回复」。「清空已处理」只是藏起来，下次抓取不会再冒出来。
6. 只保留最近 30 天的评论，最多 1000 条。

三½、热点雷达
━━━━━━━━━━━━━━━━━━━━━━━━
打开方式：首页或搜索页面板里点「热点雷达 N ↗」（N 是最近收集到的热帖数）；或者右键点回关助手图标 →「热点雷达」。

1. 收集「新发的、每小时浏览 ≥ 5000」的帖子（默认只收发出 6 小时内的）：
   - 顺手收：你刷首页、搜索页、个人主页时，看到的符合条件的帖子自动收进来。
   - 抓取一次：在热点雷达页点「抓取一次」，插件开一个 X 搜索页（最近几小时的热门帖），自己往下翻 25 屏左右，收完自动关掉、回到这里。
   只读帖子，不点赞、不回复、不关注。收的帖子保留 3 天，最多 3000 条。
2. 页面上统一展示：
   - 一句话总结：视频/图片/纯文字哪种多、长短、蓝 V 占比、反复出现的词。
   - 共同点：每小时浏览中间值、视频/图片/纯文字比例、长度、蓝 V、带话题标签、带链接、带问句、引用帖、点赞率、回复率。
   - 热词（出现在几条热帖里）、热门词组、话题标签、常被提到的账号和反复上榜的作者。
   - 热帖列表，按每小时浏览排。点任何一个词，列表就只剩带这个词的帖子，词会标亮。
3. 上面可以选：看最近 3/6/12/24 小时或 3 天发的、每小时浏览门槛（5000/1万/2万/5万）、语言。
4. 「收集设置」里可以改：「抓取一次」的搜索条件（默认 lang:zh min_faves:20，只看中文、至少 20 个赞；
   想只看航空，可以改成「航空 OR 飞机 OR 民航 lang:zh」）、只收发出几小时内的、收集门槛。
5. 热词是按「在几条热帖里都出现」数的，帖子越多越准。刚开始只有几条时，热词会比较散。

━━━━━━━━━━━━━━━━━━━━━━━━
四、发帖排期表
━━━━━━━━━━━━━━━━━━━━━━━━
打开方式：首页或搜索页面板里点「发帖排期表 ↗」；或者在浏览器右上角回关助手图标上点右键 →「选项」。

1. 左边是全天 24 小时的表格：一行一个小时（00 时到 23 时），每行按间隔分格，默认 20 分钟一格，一天 72 格。
   打开时自动滚到现在这个小时（浅蓝色那一行）。间隔可以改成 10/15/30 分钟或 1 小时。
   格子颜色：白色 = 空；蓝色 = 已经写好、等着发；绿色 ✓ = 已发或已交给 X 定时；红色 ! = 错过了；灰掉 = 时间已过的空格子。
2. 点左边一个格子，右边编辑：
   - 写文字，下面显示字数（X 的算法：中文算 2，链接算 23，超过 280 会提示）。
   - 加图片或视频：点「＋ 添加图片/视频」，或者拖进框里，或者在文字框里直接粘贴截图。
     图片最多 4 张；GIF 只能单独 1 张；视频只能单独 1 个（MP4 或 MOV，插件这边不限大小；X 那边的上限看你的账号，Premium 能传很大的视频）。
     大视频存在你电脑上的插件里，占硬盘空间；格子清空或过期两周后会自动删掉。视频越大，放进发帖框和上传要等得越久。
     太大的图会自动压缩到 X 能发的大小。图片左下角的「←」可以调顺序，右上角「×」删掉。
   - 右边「发出去的样子」实时预览：你的头像、名字、文字、话题和链接的颜色、图片的排版，跟 X 上差不多。
     可以切换深色/浅色看效果。名字和头像来自你上次打开 X 时的账号。
   - 「↑ 上一格」「下一格 ↓」快速切换。
   一次写很多条文字：展开「批量填入文字」，粘贴，每条之间空一行，点「填进空格子」。图片再一条条加。
3. 发出去有两种方式：
   A. 交给 X 定时（推荐）：点某一格的「交给 X 定时」，或者点「把这天还没发的都交给 X 定时」。
      插件会打开 X 的发帖框、填好文字、在 X 的定时窗口里选好时间、再放好图片或视频，屏幕上方会出现绿色提示。
      「交给 X 后自动点安排」开着时（默认开），定时设好、图片传完后，会倒数 3 秒自动点「安排」，批量的会一条接一条做完，你看着就行。
      倒数时点提示条上的「取消，我自己看看」可以叫停，改成你自己点。
      插件只会点已经变成「安排」的按钮；如果按钮还是「发帖」（定时没设上），绝不会点，免得帖子马上发出去。
      不想自动点：在排期表设置里关掉这个开关，就改成你看一眼再自己点「安排」。
      交给 X 之后，到点由 X 自己发，电脑关了也会发。格子会标绿色「X 已定时 ✓」。
      已经过了时间、或者 3 分钟内就到点的格子，X 不让定时，会跳过。
   B. 到点提醒：没交给 X 的格子，到点电脑会弹「该发帖了」。点提醒打开发帖框，内容和图片/视频会自动放好，你点「发帖」。带视频的要等它上传完。
      这种要电脑开着、Chrome 开着。过了 10 分钟没发，格子标红「错过了」，可以点「现在发」补发。
4. 如果插件没能自动放好图片或选好时间（X 改了页面），提示会变黄，你手动点发帖框下面的图片或日历图标补上就行。
   黄色提示上有「复制诊断信息」按钮，点一下，把复制的内容发给 Claude，方便修。

提醒：每 20 分钟一条，一天十几个小时就是几十条。发得太密，粉丝的时间线会被你刷屏，每条的曝光反而会下降。
先从每小时一条、只排白天开始，看数据再加密。

━━━━━━━━━━━━━━━━━━━━━━━━
五、今日回复计数
━━━━━━━━━━━━━━━━━━━━━━━━
你每点一次 X 的「回复」按钮发出回复，插件就记一条：
- 面板上显示「今天已回复 128 / 500」，到了目标数字变绿。目标数可以在首页面板里改。
- 你回复过的帖子，在首页、搜索页上右上角会标绿色「已回」，免得同一条回两次。
- 同一条帖子回复多次只算一次。发新帖不算回复。
- 如果点了回复但 X 发送失败，也会被算进去，数字只是大概。

━━━━━━━━━━━━━━━━━━━━━━━━
六、定时提醒
━━━━━━━━━━━━━━━━━━━━━━━━
到点不再弹系统通知，换成两种更好看到的方式：

1. X 页面顶上的蓝色提示条：「该找互关帖了（回复 ≥ 150）」，带三个按钮：
   - 「打开下一条 →」：直接打开下一条回复够多、还没处理过的互关帖。
   - 「15 分钟后再提醒」：这会儿不方便，晚点再说。
   - 「×」：这次不去了，下一轮照常提醒。
   你开着几个 X 页面，每个页面都会出现；在任何一个点了，其他的也会一起消失。
   写帖子、排期的时候（发帖框打开时）不会出现，免得挡住。
2. 浏览器右上角回关助手图标上的数字：离下次提醒还有几分钟，比如「12」。到点变成红色「!」。

   点图标也能直接打开下一条互关帖。（拼图图标里把回关助手钉住，才会一直显示。）

倒计时怎么算（按关注人数算一轮，关满才开始倒数）：
   - 到点提醒后，倒计时停住，图标是红色「!」。
   - 点「打开下一条」开始一轮，图标变成「▶0」。之后每关注一个人加 1：「▶1」「▶2」……
     到点后你直接在帖子里开始关注，也算开始了一轮。
   - 一条帖子关不满，点「下一条互关帖 →」换帖子接着关，人数一直累计，不清零。
     标「已处理」只是让帖子变灰，不会结束这一轮。
   - 关满（默认 15 个，可以在首页面板「每轮关注几个人」里改）的那一刻，开始重新倒数 15 分钟。
   - 遇到特殊情况，随时可以「清零，重新计时」：把这一轮已关注的人数清零，从这一刻开始重新倒数 15 分钟。三个地方都能点：
       · 首页/搜索页、帖子页面板最上面那条计时状态旁边的「清零，重新计时」按钮
         （那条状态会显示「下次提醒还有 8 分钟」「这一轮已关注 7 / 15」或「到点了」）
       · 右键点浏览器右上角的回关助手图标 →「清零，重新计时」
       · 到点提示条上的 ×
     右键图标还有「现在开始一轮」：不等倒计时，马上开始数关注人数。
   - 一轮里超过 1 小时没再关注任何人，会自动结束这一轮、开始倒数，不会卡住。
   - 倒数还没到的时候你关注的人，不算进下一轮。

- 改间隔或关掉：X 首页或搜索页面板里，「定时提醒我去找互关帖」选「每 30 分钟」「不提醒」等。
- 想试试效果：面板里点「马上提醒一次（试试看）」。
- 只有 Chrome 开着的时候才会提醒。

━━━━━━━━━━━━━━━━━━━━━━━━
七、清理未回关
━━━━━━━━━━━━━━━━━━━━━━━━
1. 打开你自己主页的「正在关注」页面：https://x.com/你的用户名/following
2. 点「自动下滑加载」。没回关你的人左边有红线，旁边有「取关」「保留」按钮。
   快速找下一个：
   - 点面板上蓝色的「下一个未回关 ↓」，或者按 D 键，页面会跳到下一个红色「未回关」的人，并用红框圈出来。
     当前加载的列表里没有了，会自动往下滑、让 X 加载更多再找。
   - 「取关后自动跳下一个」默认开着：点完「取关」，页面自动跳到下一个。不想要就点一下关掉。
   关注后先给对方 3 天时间回关：
   - 3 天内刚关注、还没回关的人，左边是黄线，标着「刚关注 · 还剩 2 天」，不显示「取关」按钮，免得误删。
   - 满 3 天还没回关，才变成红色「未回关」，可以取关。
   - 等几天可以在面板里改。改成 0 就是不等。
   - 只有用 v2.9 以后的插件关注的人才有关注时间。升级前关注的人没有记录，会直接按「未回关」显示；
     这些人在列表最上面，刚升级的这几天，最上面那批先别清。
   - 「导出未回关名单」也不包含还在等待期的人。
3. 「淡化已互关」可以让互关的人变淡；「导出未回关名单」存一份 CSV 表格。

取关池（攒下可以取关的人，以后不用再打开「正在关注」页一点点刷）：
  - 规则和上面一样：你关注了他、他没回关、过了等待期、没点「保留」、没取关过。
    你在「正在关注」页上滑过的人，符合的会自动放进取关池；回关了、点了保留、取关了，会自动移出。
    所以可以找个时间在「正在关注」页点「自动下滑加载」滑一遍，把人都收进池子。
  - 面板右上角「取关池 N」就是池子里有多少人，首页、搜索页、帖子页、「正在关注」页都能点开。
  - 关注得最久的排在最前面。点「取关」，或者按 D 取关池子里的下一个，每次只取关一个人。
  - 取关前插件会先问一下 X 对方现在有没有回关你：回关了就不取关，直接移出池子，免得误删。
  - 「保留」：以后不取关他，和「正在关注」页的保留一样。「主页」：先看看这个人。
  - 一天 150 个的上限照样算：到了以后要点两次才能继续。
  - 「清空取关池」只是清空名单，不会取关任何人。

八、上限提醒
━━━━━━━━━━━━━━━━━━━━━━━━
- 关注：不设上限，面板只显示今天已关注几个。X 自己的限制仍然有效，碰到时插件会提示你停下。
- 取关：一天 150 个。到了以后，要点两次才能继续。
- 关注时别连续一口气点，每关注几个人停一下。

九、连接「X 时间工作流」插件
━━━━━━━━━━━━━━━━━━━━━━━━
时间工作流是另一个独立的插件，把一天的运营排成时间线。装了它以后：
- 回关助手会把发帖排期表、今天回复数、待回复评论数发给它，排期表一改它马上更新。
- 面板里的「时间工作流 ↗」、右键图标里的「时间工作流（另一个插件）」可以打开它。
- 没装它的话，点这个按钮会提示你先装；回关助手其他功能完全不受影响。
- TG二创「发帖」页挑好的视频和文案，经时间工作流送过来，自动放进发帖排期表（和你手动加的视频一样存，格子上看得到）。
  想要的时间已经有内容或者已经过了，往后挪到下一个空格子。放好以后照常点「交给 X 定时」。
- 时间工作流里能看到待关注池有几个人、今天关注了几个、这一轮关了几个，点「打开待关注池」会打开 X 首页并展开池子。
  关注还是你自己按 F，时间工作流和回关助手都不会自己关注任何人。

给以后更新回关助手的人：这部分代码在 workflow-bridge.js，另外有 4 处标着【时间工作流】的改动，更新时保留：
  1. background.js 末尾：try { importScripts("workflow-bridge.js"); } ...
  2. content.js 面板里「发帖排期 ↗」那一行下面的「时间工作流 ↗」按钮
  3. content.js 里这个按钮的点击事件（在「待回复评论」按钮的点击事件上面）
  4. content.js 扫首页帖子的函数末尾 wfPoolHash() 和下面的 wfPoolHash 函数（打开待关注池用）

十、出问题怎么办
━━━━━━━━━━━━━━━━━━━━━━━━
X 经常改网页。如果出现下面的情况，截图发给开发者更新：
- 帖子页每个人都显示「可能未关注」
- 取关提示「没取关成功」
- 「关注」按钮每次都提示没成功、自动打开主页
- 面板没出现
