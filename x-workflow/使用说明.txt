X 时间工作流  v1.4.1

把一天的 X 运营排成一条时间线：
- 帖子：从「回关助手」的发帖排期表实时同步
- 互关池、每一轮关注了几个人：也来自回关助手
- 自动回复：在时间线上直接开始「X 自动回复流程」，看进度、暂停、停止
- TG二创：在时间线上叫它「下载并处理」，看它在做什么
- 到点自动：步骤上设的动作（自动回复、打开互关池、叫 TG二创 开始……），到时间自己做
- 其他步骤：你自己加、改、删，可以只做一次，也可以每隔多久重复做一次
这是一个独立的插件，和回关助手、X 自动回复流程分开装。

━━━━━━━━━━━━━━━━━━━━━━━━
一、安装 / 升级
━━━━━━━━━━━━━━━━━━━━━━━━
第一次装：
  1. 解压，把「时间工作流」文件夹放在一个不会误删的位置。
  2. Chrome 地址栏输入 chrome://extensions 回车，打开右上角「开发者模式」。
  3. 点「加载已解压的扩展程序」，选中「时间工作流」文件夹。
升级：把新文件覆盖到原来的「时间工作流」文件夹，在 chrome://extensions 里点它的刷新按钮。之前改过的步骤都还在。

另外两个插件也要是新版：回关助手（带 workflow-bridge.js 的那版，要「打开待回复评论并抓取」的话用最新的 workflow-bridge.js）、X 自动回复流程 1.1.0。
TG二创 要 1.9.0 以上，开着就会自动连上。
装好后打开一次 X 网页（已经开着的就刷新一下），三个插件就连上了。需要 Chrome 116 或更新的版本。

━━━━━━━━━━━━━━━━━━━━━━━━
二、打开
━━━━━━━━━━━━━━━━━━━━━━━━
- 点浏览器右上角时间工作流的图标（橙色）。
- 或者在 X 首页、搜索页的回关助手面板里点「时间工作流 ↗」，或者右键回关助手图标 →「时间工作流（另一个插件）」。
已经开着的话会直接切过去，不会重复开。

━━━━━━━━━━━━━━━━━━━━━━━━
三、时间线上的东西
━━━━━━━━━━━━━━━━━━━━━━━━
- 圆点 = 步骤。按住圆点上下拖可以改时间（每格 5 分钟），也可以点一下圆点用 ↑ ↓ 键。
- 橙色方点 = 排期表里的帖子，显示文字、图片/视频和状态（X 已定时 ✓ / 已发 ✓ / 待发 / 错过了）。
  要改就去排期表改；没交给 X 的可以直接点「交给 X 定时」，错过的点「现在发」。
  每条下面写着几点开始回这条的评论（发出后 10 分钟）。
- 菱形 = 每小时一行，合并显示这一小时里的「关注新人」轮次和你设的重复动作：
  · 关注新人：一格是一轮，「10:20 ✓ 6」= 那一轮关注了 6 个人（回关助手自动统计，不用打勾）；划掉 = 那一轮没关注；蓝色 = 现在这一轮。
    「关注新人」也是一个步骤：在「编辑步骤」里能改间隔、从几点到几点、哪几天，不要了就删掉。
  · 重复动作：一格是一次。到点那一格会变色，做完点一下打勾 ✓，点错了再点一下取消。划掉 = 那一次没做。
- 现在所在的那一步会高亮、标着「现在」；已经过去的变淡。
- 上面一排切换今天到后面 6 天。

━━━━━━━━━━━━━━━━━━━━━━━━
四、加、改、删步骤
━━━━━━━━━━━━━━━━━━━━━━━━
点「编辑步骤」进入编辑模式：
- 每一步右上角有「编辑」「删除」。删了可以马上点下面的「撤销」。
- 步骤之间有「＋ 在这里加一步」，新加的步骤默认时间在前后两步中间。
- 「恢复默认步骤」回到最初那 8 步（也能撤销）。
- 点「完成」退出。帖子是排期表里来的，不在这里改。

编辑一步时可以设：
- 名称
- 怎么安排：
  · 只做一次：开始时间、大概多久
  · 重复做：每隔多久（10 分钟到 3 小时，或者自己填几分钟）、从几点到几点、每次大概多久。下面会直接算出一天几次、哪几个时间。
- 类型（准备素材 / 发帖 / 互动 / 复盘 / 其他），决定颜色
- 要做的事（一行一条）、用的工具（显示成小标签）
- 卡片上的按钮：打开发帖排期表 / 打开待回复评论 / 打开互关池 / 启动 X 自动回复流程 / 打开一个网址
- 哪几天做：比如只在一三五做，其他天的时间线上就不显示这一步
- 挂机：时间下面标「挂机」
- 到点提醒：每一步可以单独开关（重复做的每一次到点都会提醒）

━━━━━━━━━━━━━━━━━━━━━━━━
五、自动回复（X 自动回复流程）
━━━━━━━━━━━━━━━━━━━━━━━━
按钮选「启动 X 自动回复流程」的步骤（默认的「自动回复 第 1 轮 / 第 2 轮」就是），可以设这一轮回复几条、从哪个首页标签开始。
间隔、重试、乱码过滤这些，还是用自动回复流程弹窗里的设置。
- 还没开始：点「▶ 开始自动回复」。用已经开着的 X 页面；没开的话先帮你打开 X 首页。
- 运行中：进度条、现在在做哪一步、最近 3 条日志，可以暂停 / 继续、停止、切到那个 X 页面。
- 跑完以后：成功几条、跳过几条、几点开始几点结束，「查看这轮日志」看全部，「再跑一轮」可以再来。
- 到点自动开始：编辑这一步时勾上。到点会自己开始（Chrome 要开着），并弹一个通知。默认关着。
  X 对自动回复查得严，每天总量最好控制在 60 条以内，几轮加起来别超。

━━━━━━━━━━━━━━━━━━━━━━━━
六、到点自动做
━━━━━━━━━━━━━━━━━━━━━━━━
编辑一步时，选了「卡片上的按钮」就会出现「⏰ 到点自动…」，勾上后到时间自己做：
- 启动 X 自动回复流程：开始这一轮自动回复（X 页面没开的话先打开 X 首页）。同一轮一天只自动跑一次。
- 启动 TG二创：叫 TG二创 下载并处理 / 只下载 / 只处理。TG二创 要开着。
- 打开待回复评论：打开那个页面，并点「抓取最新评论」。
- 打开互关池：打开 X 首页并展开待关注池，开始这一轮计数。关注还是你自己按 F，不会自动关注任何人。
- 打开发帖排期表 / 打开一个网址：打开那个页面。
- 重复做的步骤（比如「关注新人」每 20 分钟）：每一次到点都做。
有按钮的步骤默认都勾着；不想某一步自动做，编辑它，取消勾选就行。卡片上标着「⏰ 到点自动」，到点前写着「会自动…」，做完写着「✓ 几点已自动…」，没做成写着原因（比如「TG二创 没开」）。

时间线上方的「⏰ 到点自动做」：
- 取消勾选 = 全部不自己做，到点只弹提醒。
- 「今天先暂停」= 今天都不自己做，明天自动恢复。
要求：Chrome 开着。电脑在睡眠、Chrome 刚好没开错过的，10 分钟内醒来会补做；超过 10 分钟就不补了（免得一开机把一上午的事一口气全做了）。
每次自动做了都会弹一个通知；没做成的一定会弹，告诉你原因。

━━━━━━━━━━━━━━━━━━━━━━━━
七、TG二创
━━━━━━━━━━━━━━━━━━━━━━━━
TG二创（1.9.0 以上）开着时，会在本机开一个只给时间工作流用的小接口（127.0.0.1:38719），时间工作流用它：
- 看 TG二创 在不在、是不是正在下载或处理、最近几行日志（顶上「TG二创」那一行，和按钮是「启动 TG二创」的步骤卡片）
- 叫它开始「下载并处理 / 只下载 / 只处理」，或者停止
别的网页、别的插件都用不了这个接口。下载哪些群、怎么处理，都用 TG二创 里的设置。
TG二创 没开时，到点叫不动它，卡片和通知会告诉你；建议把 TG二创 加到「登录项」里，开机自动打开。

━━━━━━━━━━━━━━━━━━━━━━━━
八、互关池
━━━━━━━━━━━━━━━━━━━━━━━━
时间线上方的「互关池」一栏，数据来自回关助手：池子里还有几个人、今天关注了几个、这一轮的进度、最容易回关的前 5 个人。
「打开互关池，按 F 关注 ↗」会打开 X 首页并展开回关助手的待关注池，同时开始这一轮计数。然后连按 F，每按一下关注一个。
每一次关注都是你自己按的，三个插件都不会自己关注任何人。
每轮多长跟回关助手的「定时提醒我去找互关帖」一样，想每 20 分钟一轮就在回关助手面板「设置」里选「每 20 分钟」。
时间线上的「关注新人」默认 10:00 到 22:40、每 20 分钟一轮；要改时间、间隔或删掉，在「编辑步骤」里改（删了想要回来，点「恢复默认步骤」）。

━━━━━━━━━━━━━━━━━━━━━━━━
九、到点提醒
━━━━━━━━━━━━━━━━━━━━━━━━
- 每一步到点弹通知，比如「该做了：挑素材」，点通知打开时间工作流。到点自动做的步骤，弹的是「已自动开始：…」。
- 帖子发出（或已交给 X 定时）10 分钟后提醒「该回评论了」。
- 全部关掉：取消勾选「到点弹提醒」。只关某一步：编辑那一步，取消「到点提醒」。
- 「该发帖了」「该找互关帖了」的提醒还是回关助手负责，这里不会重复弹。
- 只有 Chrome 开着的时候才会提醒。

━━━━━━━━━━━━━━━━━━━━━━━━
十、顶上的连接状态
━━━━━━━━━━━━━━━━━━━━━━━━
回关助手、X 自动回复流程、TG二创 各一行：
- 绿点：正常。它们每分钟会发一次最新数据。
- 黄点：超过 3 分钟没收到数据，插件可能被关掉、在更新，或者还是旧版本。显示的是上次的数据。
- 灰点：还没连上。装好新版，再打开（或刷新）一次 X 网页。

三个插件之间只传排期、进度、日志这些文字和数字，不经过任何服务器。
时间工作流只能叫回关助手打开排期表、待回复评论（并抓取评论）、待关注池，把某一格交给 X 定时或打开发帖框；
只能叫自动回复流程开始一轮、暂停、继续、停止、切到它的页面；只能叫 TG二创 开始下载/处理或停止。别的什么都做不了，也不能关注任何人。
