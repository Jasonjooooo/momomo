第一次设置（只需一次）

  1. 在 Telegram 搜索 @BotFather，发送 /newbot，按提示起个名字，用户名要以 bot 结尾（如 jason_video_bot）
  2. BotFather 会回复一串 Token（形如 123456:ABC-xyz…），复制粘贴到下面「机器人 Token」
  3. 点上面「启动机器人」
  4. 在 Telegram 打开你的机器人，点「开始 / Start」——你就成了它的主人（别人用不了）
  5. 新建一个私有频道当「素材库」→ 频道设置 → 管理员 → 添加你的机器人 → 回到频道发一条 /bind
  6. 以后在任何频道看到视频，直接转发给机器人（可多选一起转发），它就会自动筛选

需要能连上 Telegram：使用「账号」页里填的代理。AI 分类使用「效果 → AI 解说配音」里填的 API Key。
