① Telegram API

还没有？打开 my.telegram.org → 手机号登录 → API development tools → 随便填个英文应用名创建，就能看到 api_id 和 api_hash。创建时一直报 ERROR 的话，换个代理节点再试。

② 代理 国内需要

端口

用 Clash / ClashX / Clash Verge 等：地址填 127.0.0.1，端口一般是 7890（类型选 SOCKS5 或 HTTP 都行）。 如果代理软件开了「增强模式 / TUN 模式」，这里可以留空。
