# X 自动回复流程 · Chrome 插件

配合「AI 回复助手」插件，在 X 首页的「为你推荐」里自动逐条回复帖子：

1. 在「为你推荐」里找到下一条还没处理过的帖子，点进去（广告、已处理过的、**你自己的帖子和回复**都会跳过）
   - 当前标签往下滑也找不到新帖子时，自动换到下一个标签：为你推荐 → 正在关注 → 新闻（顺序可在面板里改）
2. 点「AI 回复助手」的 **生成回复**（生成过之后按钮叫「换一批」，两个都认）（面板没打开时先点右侧的「AI 回复」打开）
3. 等生成完：「填入回复框」出现、没有「生成中」提示、内容稳定 1.5 秒
   - 如果出现「AI 没返回能用的回复，再点一次试试」，或 30 秒没结果，**等 4 秒再点一次**，默认最多重试 3 次，还不行就跳过这条
4. 点 **填入回复框**，确认回复框里有了文字
5. 点黑色 **回复**，等「已发送」提示出现
6. 随机等待（默认 5–8 秒），返回首页，往下滑进入下一条，重复以上步骤

## 安装

1. 打开 `chrome://extensions`，打开右上角「开发者模式」
2. 点「加载已解压的扩展程序」，选择本目录 `x-reply-flow/`
3. **刷新已打开的 X 页面**（装好插件之前打开的页面里没有运行脚本）

## 使用

1. 打开 x.com 首页（或直接停在某条帖子页面，会先回复这一条）
2. 点工具栏的插件图标，第一次建议先点 **检测页面**，看看「AI 回复」「换一批」等按钮能不能找到
3. 点 **开始**。页面左下角会出现浮窗，显示当前步骤，可以随时 **暂停 / 停止**

| 设置 | 默认 |
|---|---|
| 首页标签顺序 | 为你推荐, 正在关注, 新闻 |
| 最多回复 | 30 条 |
| 每条间隔 | 5–8 秒随机 |
| 发送方式 | 直接发送（可勾选「发送前等我确认」） |
| 生成失败自动重试 | 3 次，每次间隔 4 秒 |
| 多条候选回复时 | 选第一条（可改为随机） |

- 某一步超时（比如生成失败），会跳过这条继续下一条，原因写在运行日志里。
- 回复过的帖子会记下来，下次不再重复处理；可以点「清空已处理记录」重置。
- 「AI 回复助手」的按钮文字如果不一样，到「高级：按钮文字」里改成一样即可。

## 注意

- 批量自动回复可能被 X 判定为垃圾信息，导致限流或封号。间隔越短、条数越多，风险越高，请自行把握。
- 本插件通过按钮文字找到「AI 回复助手」的按钮。如果那个插件把面板放进了独立的 iframe 窗口里，就点不到了，「检测页面」会提示这种情况。
